Module 3

Public Key Cryptography

For thousands of years, the Key Distribution Problem was thought to be unsolvable. Then, in the 1970s, a mathematical breakthrough changed the internet forever: Asymmetric Encryption.

What You Will Learn

1. Secure key distribution

Learn how generating a linked Public Key (for locking) and a Private Key (for unlocking) completely defeats network eavesdroppers like Eve.

2. Man-in-the-middle

Discover the ingenious math trick that allows Alice and Bob to magically generate a shared secret over a public network without ever actually sending it.

3. Diffie-Hellman key exchange

Explore the most famous asymmetric algorithm in the world, and learn how it uses the multiplication of massive prime numbers to lock your data.

Classical Cryptography: The Substitution Cipher

Now that we know the difference between plaintext and ciphertext, how do we actually make the conversion? It requires two things: a mathematical Algorithm, and a secret Key.

The Core Processes

The Encryption Process

Encryption is the process of scrambling data into a secure format. It takes readable plaintext and passes it through an algorithm using a specific cryptographic key. Without the key, the resulting ciphertext is useless.

Formula: E(k, m) = c
(Encrypt Message 'm' with Key 'k' to get Ciphertext 'c')

The Decryption Process

Decryption is the exact reverse. It is the process of transforming data that has been rendered unreadable back to its unencrypted form. The receiver must use the exact same algorithm and the correct key.

Formula: D(k, c) = m
(Decrypt Ciphertext 'c' with Key 'k' to get Message 'm')

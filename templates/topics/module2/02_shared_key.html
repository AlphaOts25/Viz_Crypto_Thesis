The Shared Key Concept

Symmetric encryption is like a physical padlock where there is only one type of key. The sender uses the key to lock the box, and the receiver must use an identical copy of that exact same key to open it.

How Symmetric Systems Work

In cryptography, we often use characters named Alice (the sender) and Bob (the receiver) to explain how data travels.

  • Step 1: Alice and Bob agree on a secret password (the "Shared Key") beforehand.
  • Step 2: Alice runs her plaintext message and the Shared Key through a mathematical algorithm.
  • Step 3: The resulting ciphertext is sent across the internet. Even if a hacker intercepts it, it looks like random noise.
  • Step 4: Bob receives the ciphertext and runs it through the reverse algorithm using the exact same Shared Key.

The Golden Rule: If Bob's key is even one letter or symbol different from Alice's key, the decryption will fail completely.

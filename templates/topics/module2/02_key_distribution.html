The Key Distribution Problem

Symmetric algorithms like AES are mathematically unbreakable. But they all share one fatal flaw: to use a symmetric key, you must share it. If you send the key across the internet, the entire system breaks.

♾ Infinite Regress — The Recursive Problem
To encrypt the key, you need another key. But to send that key, you need another key... and so on forever.
Key A
→ encrypt with →
Key B
→ encrypt with →
Key C
→ encrypt with →
Key ? (never ends)
You always end up needing to securely share some key. The problem just moves, it never disappears.
⚠️ The Key Distribution Problem Is Unsolvable with Symmetric Encryption
Eve doesn't need to break the encryption. She just intercepts the key. Every router, hub, VPN server, and exit node on the internet is a potential interception point. No matter how many hops you add or tunnels you create, the key must physically travel from Alice to Bob — and Eve can sit on any node along the way.

Encrypting the key itself just creates a new key that needs sharing — an infinite regress. This is why symmetric encryption alone cannot secure the internet.
Diffie-Hellman (1976) solved this by making key transmission unnecessary. Alice and Bob each work with a public number and a private secret. They exchange only public values — which Eve can see — yet independently compute the same shared secret without ever sending it. Eve intercepts everything and still can't reconstruct the key.

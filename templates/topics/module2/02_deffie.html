Topic 3

The Key Exchange Problem

Diffie-Hellman is a key exchange method that allows two people to create the same secret key without directly sending the key to each other. It was designed to solve the key distribution problem in symmetric encryption, where both users need the same key but must avoid exposing it to attackers. Through mathematical computation, both sides can exchange public values, generate a shared secret, and use that secret for secure communication, even if someone is watching the exchange.

Enter Diffie-Hellman

In the 1970s, secure communication had a serious weakness. Symmetric encryption could protect messages, but both people first needed the same secret key. The problem was how to share that key safely without meeting in person. If Alice sent the key through an open network, Eve could intercept it and later decrypt every message. This became known as the key distribution problem.

In 1976, Whitfield Diffie and Martin Hellman introduced a new solution called the Diffie-Hellman key exchange. Instead of sending the secret key directly, both users exchange public values and use mathematics to generate the same shared secret independently. An attacker may see the exchanged values, but cannot easily compute the final secret. This idea became one of the foundations of modern public-key cryptography and secure online communication.
